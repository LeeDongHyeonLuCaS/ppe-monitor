# 현장 시야 · PPE 모니터링

이전 프로토타입의 디자인과 동작을 복원한 프론트엔드입니다.

- 왼쪽: 노트북 웹캠 화면, 카메라 켜기/끄기, 실행 모드
- 오른쪽: 현재 탐지 결과, 6개 클래스별 객체 개수
- 하단: 현재 세션 로그와 로그 지우기

600px 이상에서는 카메라와 결과를 좌우로 표시하고, 작은 휴대폰 화면에서는 위아래로 배치합니다.

## 실행

Node.js가 설치된 환경에서 프로젝트 폴더를 열고 `node server.cjs`를 실행합니다.
브라우저에서 http://localhost:5173 에 접속합니다. 별도 패키지 설치는 필요 없습니다.

종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다. 다시 볼 때도 위 명령으로 서버를 실행해야 합니다.
`npm run dev`로 실행해도 됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 대시보드 화면 |
| `styles.css` | 스타일과 반응형 좌우 배치 |
| `app.js` | 웹캠, 테스트 결과, 세션 로그 |
| `server.cjs` | 로컬 미리보기 서버 |
| `package.json` | 실행 명령 |

## 이후 Git 저장소와 배포

이번 단계는 로컬 복원까지입니다. 화면 수정 후 이 `ppe-monitor` 폴더를 저장소의 루트로 사용합니다.
상위 폴더의 이전 버전과 ZIP은 이 프로젝트에 포함하지 않습니다.

화면은 HTML/CSS/JavaScript 정적 파일 3개로 구성되어 있어 정적 호스팅에 배포할 수 있습니다.
로컬 전용 `server.cjs`는 모델 서버가 아닙니다. 모델 실행용 백엔드는 별도로 연결해야 합니다.
리소스 경로는 저장소 하위 주소에서도 사용할 수 있도록 상대 경로로 작성했습니다.

## 사용

- 실제 카메라: 카메라 켜기를 누른 후 접근을 허용합니다. 카메라 끄기나 모드 변경 시 장치를 해제합니다.
- 테스트 데이터: 실행 모드를 변경한 뒤 테스트 시작/중지를 누릅니다. 예시 수치이며 실제 모델 분석이 아닙니다.
- 세션 로그: 현재 페이지에서만 유지됩니다. 최근 50개 항목을 표시하며 새로고침 시 초기화됩니다.
- 실제 탐지 버튼은 백엔드 연결 전까지 비활성화됩니다. 영상 업로드나 모델 실행은 아직 구현하지 않았습니다.

카메라는 localhost 또는 HTTPS 환경이 필요합니다. 앱 내 미리보기에서 권한이 지원되지 않으면 일반 Chrome/Edge 브라우저에서 localhost 주소를 여세요.

## 백엔드 연결 시 필요한 합의

1. JPEG 사진 한 장을 보내 탐지 결과 한 번을 받는 API 주소와 요청 형식
2. 응답의 프레임 ID, 원본 이미지 크기, 클래스 이름, 신뢰도, 박스 좌표 및 좌표 기준
3. 클래스 ID와 이름의 정확한 대응, 모델 실행 설정
4. 프론트 개발 주소의 접근 허용(CORS), 인증 유무, 오류 응답

첫 연결은 단일 이미지로 확인하고, 이후 이전 요청 완료 후 다음 프레임을 보내는 방식으로 확장합니다. 전송 빈도는 서버 처리 속도를 측정한 뒤 정합니다.

## 탐지 대상 (요구사항)

| 화면 이름 | 프론트 표시용 키 |
| --- | --- |
| 안전모(헬멧) | `helmet` |
| 고글 | `goggles` |
| 안전조끼 | `vest` |
| 장갑 | `gloves` |
| 안전화(부츠) | `boots` |
| 사람 | `person` |

표의 키와 순서는 프론트 표시용이며, 모델의 숫자 클래스 ID와 일치한다고 가정하지 않습니다.
기존 `no-helmet`, `no-vest` 항목은 현재 화면의 탐지 대상에서 제외했습니다.

제공 ZIP의 노트북에서 확인한 기존 학습 클래스는 helmet, no-helmet, vest, no-vest, person입니다.
고글·장갑·안전화는 해당 목록에 없으므로, 위 6종의 실제 탐지를 위해 모델 담당자가 지원 모델과 클래스 대응을 확인해야 합니다.
프론트 목록을 변경해도 `.pth`의 탐지 능력은 바뀌지 않습니다. 현재 테스트 모드는 6종의 예시 데이터만 표시합니다.
장갑·안전화의 한 개/한 쌍 집계 기준도 백엔드와 합의해야 합니다. 현재 예시는 객체 개수이며 쌍으로 변환하지 않습니다.
특정 보호구가 탐지되지 않았다고 해서 미착용으로 단정하지 않습니다.

객체 개수는 고유 인원수와 다릅니다. 프레임별 탐지를 합산해 누적 인원수로 표시하지 않습니다.
